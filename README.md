# EvercodeLab_SecondTask

Структура проекта:

    csv_checker_modular/
        main.py          — запуск и итоговые счётчики
        settings.py      — пути, границы даты, регулярные выражения и списки
        checks.py        — отдельные проверки девяти столбцов и разбор значений
        rows.py          — сбор причин ошибок и распределение строк
        file_io.py       — чтение CSV и запись Excel

Результат: task2_проверенный.xlsx с листами «Корректные» и «Ошибки».
Исходный CSV не изменяется, а существующий выходной XLSX при повторном
запуске перезаписывается.

## Логика

1. main.py вызывает read_csv() из file_io.py.
2. validate_rows() из rows.py предварительно считает повторы ID и
   операций B:I, чтобы отметить все совпавшие строки.
3. validate_row() из rows.py вызывает по одной функции из checks.py для
   каждого столбца, собирает все причины ошибок и возвращает разобранные
   дату и сумму. Списки и шаблоны берутся из settings.py.
4. При отсутствии других ошибок допустимая дата в ином формате исправляется:
   строка идёт в «Корректные», а исходная строка с пометкой — в «Ошибки».
5. write_excel() из file_io.py создаёт оба листа; дату и сумму записывает
   как значения Excel.

Функции проверок в checks.py соответствуют столбцам по порядку:

| Столбец | Функция               | Что проверяет                               |
|---------|-----------------------|---------------------------------------------|
| 1       | check_id              | Шаблон TX-0001 и повторы ID                 |
| 2       | check_date            | Формат, существование и диапазон даты       |
| 3       | check_project         | Проект из списка                            |
| 4       | check_category        | Статья расходов из списка                   |
| 5       | check_description     | Непустое содержание операции                |
| 6       | check_amount          | Положительная сумма                         |
| 7       | check_currency        | Валюта из списка                            |
| 8       | check_credit_currency | Валюта Кт из списка                         |
| 9       | check_payment         | Точное значение CARD_ + валюта из столбца 7 |

parse_date() и parse_number() разбирают значения для проверок и приведения
к Excel. operation_key() приводит дату и сумму к общему виду, чтобы найти
повтор операции, даже если они были записаны по-разному.

Границы MIN_DATE и MAX_DATE включительные. Сейчас MIN_DATE задан как
2024-12-31, то есть 31 декабря 2024 года допускается. MAX_DATE — день
запуска.
